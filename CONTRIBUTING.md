# Contribuir a python-package-firewall

Por favor, sigue estas reglas antes de enviar un PR:

- Usa `ruff`, `black` e `isort` antes de cada commit.
- Agrega o actualiza tests (unitarios/integración).
- Mantén la cobertura ≥ 85%.
- Usa Conventional Commits.
- No modifiques `sys.path` ni scripts en la raíz.
- Consulta `.github/python.instructions.md` para más detalles.
